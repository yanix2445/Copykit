# Navigation

How the user moves through the app: routing and the page structure.

## Routing

- Navigation par l'état, sans routeur ni Coordinator : `NavigationSplitView` et une sélection, comme dans `CopyKit/ContentView.swift`.
- Chaque action fréquente a une entrée de menu et un raccourci clavier ; `Settings` s'ouvre avec ⌘,.
