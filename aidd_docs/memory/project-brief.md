What this project is, the problem it solves, and its domain language. The non-derivable "why", not the "how".

- Le besoin n'est pas encore cadré : il sort du brainstorm (`aidd-refine:01-brainstorm`), puis du Product Brief dans `aidd_docs/product/`.
